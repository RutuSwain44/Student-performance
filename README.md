# 🎯 Student Task Manager with AI Recommendation System

## 📌 Project Overview

Student Task Manager is a modern web application designed to help students organize, manage, and track their daily academic and personal tasks efficiently.

The application includes smart AI-based task suggestions and a recommendation engine that analyzes user activity to provide personalized productivity insights.

---

# 🚀 Key Features

## 🔐 Authentication System

* User Signup
* User Login
* Secure Local Storage Authentication

## 📝 Task Management

* Add New Tasks
* Edit Existing Tasks
* Delete Tasks
* Mark Tasks as Completed
* Task Categories
* Task Description Support
* Due Date Selection

## 🤖 AI-Based Features

### ✅ Smart Suggestion Engine

The application automatically suggests productivity tips based on task keywords entered by the user.

Examples:

* Study → "Study for 2 hours"
* Gym → "Workout for 1 hour"
* Coding → "Practice coding for 2 hours"

### ✅ Recommendation Engine

The system analyzes completed tasks and provides intelligent recommendations based on user activity patterns.

Example:

* Users completing more Coding tasks receive coding-focused recommendations.

## 🔍 Search Functionality

* Real-time task searching
* Dynamic filtering without page reload

## 📊 Dashboard Analytics

* Total Tasks Counter
* Pending Tasks Counter
* Completed Tasks Counter

## 🎨 Responsive UI Design

* Modern dashboard interface
* Responsive layout for desktop and mobile devices
* Interactive buttons and hover effects
